How to Post on GitHub Pages

Follow these simple steps to host this entire 3D portfolio live for free under your personal GitHub domain:

Step 1: Create a GitHub Repository Go to GitHub, create a new public repository named portfolio or username.github.io.
Step 2: Save as index.html Rename this file from index3.html to index.html (GitHub looks for index.html as the home page).
Step 3: Upload the File Drag and drop index.html into your repository and click "Commit changes".
Step 4: Enable GitHub Pages Go to Settings → Pages → under "Branch", select main and folder /(root) → click Save. In 1 minute, your portfolio is live worldwide!
